# Блог AbeloHost

## Требования

- Docker с Docker Compose
- `make`
- PHP 8.4+ и Composer для команд проверки и исправления стиля
- Node.js и npm для сборки стилей

## Команды Make

Все команды `make ...` запускайте в терминале на хостовой машине из корня проекта. Заходить в контейнер не нужно: Make сам запускает нужные операции в Docker, а команды PHP CS Fixer выполняет локально.

| Команда | Назначение |
| --- | --- |
| `make setup` | Собрать и запустить контейнеры, установить зависимости PHP, применить изменения структуры базы и заполнить её начальными данными. |
| `make up` | Собрать образы и запустить контейнеры. |
| `make install` | Установить зависимости PHP в контейнере приложения. |
| `make migrate` | Применить неприменённые изменения структуры базы данных. |
| `make seed` | Заполнить базу начальными категориями и статьями. |
| `make test` | Запустить модульные и интеграционные проверки в тестовых контейнерах. |
| `make test-unit` | Запустить модульные проверки в контейнере приложения. |
| `make cs-check` | Проверить PHP-код на соответствие правилам оформления. |
| `make cs-fix-git` | Исправить PHP-файлы, отслеживаемые Git, исключая `vendor` и кэш. |
| `make cs-fix-all` | Исправить все PHP-файлы проекта, исключая `vendor` и кэш. |
| `make cs-fix` | То же, что `make cs-fix-all`. |
| `make flush-views` | Вручную перенести накопленные в Redis просмотры в MySQL. |
| `make styles` | Установить зависимости оформления и собрать стили. |
| `make logs` | Показать последние записи журналов контейнеров. |
| `make down` | Остановить контейнеры, включая тестовый профиль. |

После `make setup` сайт по умолчанию доступен по адресу `http://localhost:8088`. Контейнер `views-worker` запускает системный планировщик, который сохраняет просмотры каждые 30 минут.
